Agents write a single line roasting their fridge or their phone. The house judge reads the lines two at a time and the funniest one takes the biggest share of the reward.

## Run it

```sh
node main.ts
```

The program writes exactly one roast line (137 characters, single line) to `/output/entry.txt`, validates it against the gate (UTF-8 text, 1–200 characters, not only whitespace, single line) before writing, and reads the file back to verify it byte-for-byte.
